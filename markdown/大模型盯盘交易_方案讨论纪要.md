# 大模型盯盘交易 · 方案讨论纪要

> 状态：方案讨论中（v1 未开工）
> 整理时间：2026-07
> 涉及项目：alpha-trading-bot-okx
> 用途：后期复用的设计基线文档，开工前可在此基础上细化

---

## 1. 背景与动机

把 OKX 交易所的账号 API 密钥交付给"大模型驱动的 Agent"，由其 7×24 小时：

- 盯盘（行情、持仓、资金费率、消息面）
- 实施分析（K线结构、指标、新闻等）
- 实施决策（买/卖/持有）
- 执行交易（调用 OKX API 下单）

核心诉求：**"大脑"是大模型本身**（而非仅运行一个预写好策略的 Python 脚本），人可以随时用自然语言调整思路，且系统自动运转。

---

## 2. 可行性结论

**可行**，但需要正确理解运行形态：

- 大模型 Agent 不是常驻进程，而是"被唤醒"的。
- 7×24 的正确形态 = **定时器唤醒 + 风控守卫 + 执行脚本 + 告警**，大模型只负责每周期一次的决策。
- 前提：运行机器（Mac/服务器）常开、常联网。
- 成本：每周期一次 LLM 调用，15 分钟周期 ≈ 96 次/天，小额 API 成本。

---

## 3. 两条路线对比

| | 路线 A：bot 为主，LLM 出信号 | 路线 B：大模型直接做决策（本次选定） |
|---|---|---|
| 大脑 | bot 配置的 AI 提供商（qwen/kimi 等），每次周期内调用 | 大模型 Agent 本身，可用完整工具链（查新闻、拉任意数据、复盘） |
| 稳定性 | 高，纯进程常驻 | 依赖定时唤醒 + 机器常开 + 心跳监控 |
| 风控 | 代码内建 | 必须外加一层"确定性风控守卫" |
| 灵活度 | 改策略要改代码 | 自然语言直接调思路，落盘决策日志可复盘 |
| 适用 | 策略已定型、追求极致稳定 | 策略在探索期、希望模型持续参与决策 |

**结论：选路线 B，但必须配强风控守卫（死代码，大模型碰不到）。**

---

## 4. 选定架构（路线 B）

### 4.1 主循环

```
定时器（每 15 分钟，launchd/cron + 定时子代理）
  → 唤醒大模型 Agent
  → 拉数据：行情 / 持仓 / 资金费率 / 消息面（用本地 .env 的 OKX 密钥）
  → 大模型分析并产出决策（买/卖/持有 + 理由 + 仓位建议）
  → 决策写入"风控守卫"脚本（确定性代码）校验
  → 守卫放行 → 调用 OKX API 下单
  → 决策与成交落盘存档（供复盘）
```

### 4.2 风控守卫（死代码红线，不经过大模型）

- 最大仓位 / 最大持仓名义价值上限
- 单笔风险上限（按账户百分比，如 1%）
- 单日亏损上限 → 触发即当日停止交易
- 交易冷却期（防连续抖动下单）
- Kill switch 文件：存在即停止一切交易
- 同一币种同时只允许一个仓位，v1 禁止加仓摊薄
- 仓位按"风险百分比"计算，不按固定金额

### 4.3 监控与告警

- 心跳监控：连续两次唤醒失败 / 进程挂掉 → 微信推送告警
- 异常（API 报错、下单失败、异常亏损）→ 微信推送
- 每次决策落盘：时间、行情快照、理由、守卫校验结果、成交回报

---

## 5. 安全要点（密钥管理）

1. **API Key 只开「交易」权限，绝不开「提币/划转」权限**。
2. 尽量设置 **IP 白名单**。
3. 建议用 **子账户或独立账户**，只放亏得起的钱。
4. 密钥填在本地 `.env`（已在 gitignore），**不经过聊天记录传输**。
5. `.env` 永不提交、永不出现在代码/日志中。

---

## 6. 币对选择：单币起步

**v1 决策：只交易 BTC-USDT-SWAP（单币）。**

### 6.1 为什么多币种会放大判断误差

1. **注意力稀释**：每周期看 N 个币，单币分析深度必然下降；"看不细还下单"比"看不细就不下单"危险。
2. **决策次数变多**：出错机会、手续费、滑点磨损成倍累积。
3. **相关性假分散**：山寨币与 BTC 高度同涨同跌，多币 ≈ 多仓位押同一方向，而非真分散。

### 6.2 单币（BTC）的优势

- 流动性最好、点差最小 → 滑点/磨损最小
- 资金费率最稳定 → 持仓成本可预测
- 数据最丰富、LLM 公共知识最可靠 → 判断质量最高
- 被操纵/插针相对少 → 不易被假突破打损

### 6.3 代码要求

- 币对做成**配置列表**（`TRADING_SYMBOLS`），扩容只改配置。
- 每笔风险按账户百分比计算，加币种时风控逻辑无需改动。

## 7. 扩容路线图

```
第 1 周:    BTC-USDT-SWAP          → 验证全链路：流程/风控/告警/复盘
第 2-3 周:  + ETH-USDT-SWAP        → 仍是主流币，流动性好
之后可选:   + SOL-USDT-SWAP        → 币对宇宙控制在 3 个以内
```

**扩容后新增规则：信号择优**
每周期对所有候选币打分，只交易得分最高且过阈值的 1 个（最多 2 个），而非每个都下。
→ 判断负载不变，获得"挑最强"的灵活性。

## 8. 风险提示（丑话）

- 大模型决策有不确定性，**亏损是真实可能的**，杠杆可能爆仓。
- 本系统的价值 = "纪律性执行 + 风控"，不是印钞机。
- 小仓位起步；第一周强制跑 **OKX 模拟盘 / 纸面交易**，验证"大模型当大脑"的流程后再接真钱。
- 机器断电断网期间无人在盯盘 —— 需接受该窗口风险或用服务器 + 自启缓解。
